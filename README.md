# web-calculator

A simple and responsive web-based calculator built using **HTML, CSS, and JavaScript**. This project performs basic arithmetic operations with a clean UI and smooth user experience.

---

##  Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🧹 Clear (AC) button
* ⌫ Delete (Backspace)
* 📱 Responsive design (works on mobile & desktop)
* 🎨 Modern UI with dark/light theme (optional)

---

##  Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and layout
* **JavaScript (Vanilla JS)** – Functionality and logic

##  How It Works

* User clicks buttons → Input is displayed on screen
* JavaScript captures input and performs calculations
* Results are updated dynamically
